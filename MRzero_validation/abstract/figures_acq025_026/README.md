Measured multi-echo GRE and EPI timing. Selected echoes share a first-echo display scale; the RSS curve uses one fixed support. Thirty-two measured echoes end at 58.54 ms, whereas EPI imaging samples extend to 117.09 ms. The late EPI signal therefore requires extrapolation. ## Interpretation limits

- One identified acquisition per condition; no technical-repeat error bars.
- 025 zero initialization is a separate optimization condition.
- Magnitude NRMSE includes contrast and artifacts; not pure geometric error.
- CSV-to-scan controller load association is not verified.
- No measured dynamic-B0 comparator has been identified.
- No automatic N/2 ghost ratio without reviewed, non-overlapping ROIs.
- The 128-square EPI ADC range extends beyond the last measured GRE echo.
